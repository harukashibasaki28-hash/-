# 手帳（スケジュール・睡眠管理アプリ）

Claude のチャットで運用していた手帳を、単体で動くアプリにしたものです。

- スマホ（ホーム画面に追加する PWA）とパソコンのブラウザで使えます
- データの本体は自分の Google スプレッドシート（Google Apps Script 経由）。端末には控えを置き、オフラインでも記録できます
- 有料のサーバー・API は使いません

## 使い始める

1. [GitHub Pages で公開してホーム画面に追加](docs/SETUP_PAGES.md)
2. [Google との接続（スプレッドシート＋Apps Script）](docs/SETUP_GAS.md)
3. [iPhone のアラーム（ショートカット）](docs/SETUP_ALARM.md)

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md)。

## 画面

| 画面 | できること |
|---|---|
| 今日 | 寝る／起きた／昼寝する／昼寝から起きた、タスクの追加・完了・計測、止め忘れの確認、23:00 の【min】確認、学習の遅れ警告、近い締切・報連相、Gmail の確認候補 |
| 予定 | タイムライン自動作成（空き時間の 75%・見積×実績倍率・締切/優先度順・重いものは午後）、後ろ倒し候補、Google カレンダーへ登録 |
| 振り返り | 今日の進捗（睡眠・昼寝・完了率・【min】・倍率・平均ずれ）と課題・改善策、週の振り返り（平均睡眠・就寝のばらつき・完了率の推移・翌週に変えること） |
| 学習 | 科目ごとの進み具合、期限から逆算した 1 日の量、遅れ警告、科目の追加・編集・終了、終了した科目の記録 |
| 報連相 | 期限が近い順 |
| ログ | 日次ログ表（CSV 書き出し） |
| 設定 | Google との接続、学習計画シート・Gmail、目標時刻、固定予定、毎日のタスク、時間割の結び付け、改善策ルール、JSON の書き出し・読み込み |

## 開発

```bash
npm test            # 自動テスト（Node.js 22、追加インストール不要）
npm run build:gas   # dist/gas/Code.gs を作り直す（src/core か gas/ を変えたら必ず実行）
python3 -m http.server 8000   # http://localhost:8000 で動作確認
```

| フォルダ | 中身 |
|---|---|
| `src/core/` | 計算（睡眠・繰越・完了率・学習の自動進行・タイムライン・学習計画シートの読み取り）。GAS と共通 |
| `src/analysis/` | 改善策ルールの評価。`registerAnalyzer()` で AI 分析などを追加できる |
| `src/store/` | 端末内の控え（IndexedDB）と同期 |
| `src/ui/` | 画面 |
| `config/` | 初期設定 `defaults.json`、改善策ルール `rules.json` |
| `gas/` | Apps Script のソース → `dist/gas/Code.gs` に 1 つにまとめて貼り付ける |
| `tests/` | 自動テスト（GAS はにせものの Google サービスの上で動かして確認） |
