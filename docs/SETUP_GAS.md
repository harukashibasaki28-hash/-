# Google との接続の設定（スプレッドシート＋Apps Script）

所要時間：20〜30 分。パソコンのブラウザ（Chrome など）で行うのがおすすめです。
ここで作るもの：

- スプレッドシート「手帳DB」：データの本体（アプリが自動で書き込みます）
- Apps Script（GAS）：アプリとスプレッドシートの橋渡し、21:50 の翌日 To Do、Gmail、23:00 の確認
- キー（合言葉）：あなたの端末だけが読み書きできるようにするための長い文字列

---

## 1. スプレッドシートを作る

1. https://drive.google.com を開く
2. 左上の「＋ 新規」→「Google スプレッドシート」→「空白のスプレッドシート」
3. 左上の「無題のスプレッドシート」をクリックして、名前を **手帳DB** にする

## 2. Apps Script を開いてプログラムを貼る

1. 手帳DB のメニュー **「拡張機能」→「Apps Script」** を押す（新しいタブが開きます）
2. 左上の「無題のプロジェクト」をクリックして、名前を **手帳API** にする
3. GitHub のこのリポジトリで **`dist/gas/Code.gs`** を開き、右上の「Raw」（またはコピーのアイコン 📋）で全文をコピー
4. Apps Script の画面に戻り、`コード.gs`（Code.gs）の中身を**全部消して**、コピーしたものを貼る
5. 💾（保存）を押す

## 3. 設定ファイル（appsscript.json）を入れる

1. Apps Script の左の ⚙️「プロジェクトの設定」を押す
2. **「"appsscript.json" マニフェスト ファイルをエディタで表示する」** にチェック
3. 左の `<>`「エディタ」に戻ると `appsscript.json` が増えているので開く
4. 中身を全部消して、このリポジトリの **`dist/gas/appsscript.json`** の内容を貼り、💾 保存
   （タイムゾーン `Asia/Tokyo` はここで設定されます）

## 4. 初回セットアップを実行する

1. 上部の関数の選択欄（「myFunction」などと表示されている所）で **`setup`** を選ぶ
2. **▶ 実行** を押す
3. 「承認が必要です」→「権限を確認」→ 自分の Google アカウントを選ぶ
4. 「Google はこのアプリを確認していません」と出たら、左下の **「詳細」→「手帳API（安全ではないページ）に移動」**
   （自分で作ったプログラムなので問題ありません）
5. 一覧の権限（スプレッドシート・カレンダー・Gmail・メール送信など）を確認して **「許可」**
6. 下の「実行ログ」に、次のような表示が出ます：

   ```
   セットアップ完了。
   アプリの「設定」→「Google との接続」に、ウェブアプリの URL と次のキーを貼ってください:
   3f9c…（64 文字）
   ```

   この **64 文字のキー**をコピーしておきます（あとから `showKey` を実行しても表示できます）。

このとき自動で行われること：
- 手帳DB にシート（days / tasks / hourensou / templates / subjects / config / inbox / dayplans / はじめに）を作成
- 全シートに保護（編集しようとすると警告）をかける
- Gmail に「手帳済」ラベルを作成
- Google カレンダーに毎日 23:30「【手帳】寝る準備」（通知付き）を作成
- 自動実行の予約：21:50 翌日の To Do／23:00【min】の確認メール／30 分ごとの Gmail 確認／毎日 3 時の点検

## 5. ウェブアプリとして公開する

1. 右上の **「デプロイ」→「新しいデプロイ」**
2. 左の ⚙️（種類の選択）→ **「ウェブアプリ」**
3. 次のように設定：
   - 説明：手帳API（なんでも可）
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**
4. **「デプロイ」** → 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にする理由：ホーム画面のアプリから呼び出すために必要です。URL を知られても、**キーが合わなければ何も読み書きできません**。キーはあなたの端末の中だけに保存され、GitHub には置かれません。スプレッドシート自体は誰とも共有されません。

## 6. 手帳アプリに貼る

1. 手帳アプリを開き、下の **⚙️ 設定** → 「Google との接続」
2. **ウェブアプリの URL** と **キー** を貼り、「保存して接続」
3. 右上が「同期済み」になれば完了です
4. 同じ画面の「学習計画シート・Gmail」で：
   - **学習計画スプレッドシートの URL**：「学習計画（英語・FP2級）」をブラウザで開いたときのアドレスをそのまま貼る
   - **差出人**：`mizuho-fg@mail.axol.jp`
   - 「保存」
5. パソコンでも同じアプリの URL を開き、同じ URL とキーを入れると、同じデータが見られます

## 7. 今の手帳の記録を移す

1. Claude のチャットで、今の記録を JSON で出してもらい、ファイル（例：`techo.json`）に保存するか、テキストをコピー
2. 手帳アプリ → 設定 → 「データ」→ **「JSON を読み込む」**（ファイル）または「JSON を貼り付けて読み込む」
3. 件数の確認が出るので **「マージ」** を選ぶ
4. 自動でスプレッドシートに保存され、ほかの端末にも反映されます

---

## プログラムを更新するとき

アプリ側（GitHub Pages）は自動で更新されますが、GAS は手で貼り替えます。

1. `dist/gas/Code.gs` の新しい内容を、Apps Script の `コード.gs` に貼り替えて保存
2. **「デプロイ」→「デプロイを管理」→ ✏️（編集）→ バージョン：「新バージョン」→「デプロイ」**
   （こうすると URL が変わらず、アプリの設定はそのままで使えます）

## スマホをなくしたとき（キーの作り直し）

1. Apps Script で関数 **`resetKey`** を選んで ▶ 実行 → 新しいキーが実行ログに出ます
2. 古いキーは使えなくなるので、手元の端末の設定に新しいキーを貼り直します

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| 「キーが違います」 | キーの前後に空白が入っていないか確認。`showKey` を実行して貼り直す |
| 「GAS の応答を読めません」 | URL が `/exec` で終わるウェブアプリの URL か確認（`/edit` ではない） |
| 学習計画シートの予定が入らない | 設定の学習計画シートの URL・シート名（予定一覧／毎日の時間割）を確認 |
| 21:50 に翌日の To Do ができない | Apps Script の ⏰「トリガー」に `nextDayJob` があるか確認。無ければ `setup` をもう一度実行 |
| スプレッドシートを誤って書き換えた | スプレッドシートの「ファイル」→「変更履歴」→「変更履歴を表示」で元に戻す |

Apps Script の左の ≡「実行数」で、自動実行の成功・失敗とエラー内容を確認できます。
