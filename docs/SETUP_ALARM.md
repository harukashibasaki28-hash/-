# iPhone のアラームを手帳から設定する（ショートカット）

ホーム画面のアプリ（PWA）は、閉じている間に決まった時刻で音を鳴らすことができません。
そこで「寝る」「昼寝する」を押したときに、iPhone の**時計アプリのアラーム**を作れるようにします。
一度だけ、次のショートカットを作ってください（5 分ほど）。

## ショートカット「手帳アラーム」の作り方

1. iPhone の **「ショートカット」** アプリを開く
2. 右上の **＋** で新しいショートカットを作る
3. 上の名前を **手帳アラーム** にする（設定画面の「ショートカットの名前」と同じにします）
4. 「アクションを追加」で、次の 2 つを順に追加：
   1. **「入力から日付を取得」**（検索欄に「日付」と入力すると出ます）
      - 入力は「ショートカットの入力」にする
   2. **「アラームを作成」**（検索欄に「アラーム」）
      - 時刻：前の「日付」
      - ラベル：手帳
5. 下の ⓘ（詳細）で **「共有シートに表示」はオフ**、受け取る入力は「テキスト」で OK
6. 完了

## 使い方

- 「🌙 寝る」→ 表示される **「⏰ iPhone のアラームを 06:00 に設定」** を押す
- 「😴 昼寝する」→ **「⏰ iPhone のアラームを（20 分後の時刻）に設定」** を押す
- 初回だけ「“手帳”にショートカットを実行することを許可しますか？」などと聞かれたら「許可」

## ショートカットを使わない方法（.ics）

「📅 カレンダー（.ics）で通知を追加」を押すと、その時刻に通知が出る予定ファイルができます。開いて「追加」すると、カレンダーの通知として鳴ります（Android・パソコンでも使えます）。

## そのほかの通知

| 時刻 | 方法 |
|---|---|
| 23:00 【min】が未完了 | GAS から自分宛てにメール（Gmail の通知で届く）。アプリを開けば画面上部にも一覧 |
| 23:30 寝る準備 | Google カレンダーの毎日の予定「【手帳】寝る準備」の通知 |
| タイマーの止め忘れ（2 時間） | アプリを開いている間は通知、閉じていた場合は次に開いたときに確認 |
